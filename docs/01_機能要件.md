## F-1. 用語図鑑・検索

### 概要
フロントエンド用語・UI部品名を図鑑形式で閲覧・検索できる。

### 詳細要件
| ID | 要件 | 優先度 |
|---|---|---|
| F1-1 | キーワード検索（部分一致・ひらがな/カタカナ/英語表記ゆれ対応） | MVP |
| F1-2 | カテゴリ絞り込み（HTML / CSS / JavaScript / UI部品 / レイアウト / 開発用語 など） | MVP |
| F1-3 | 難易度タグ（初級 / 中級 / 上級）で絞り込み | MVP |
| F1-4 | 五十音・アルファベット順の一覧表示 | MVP |
| F1-5 | 「見た目から探す」画像グリッドからの逆引き検索 | フェーズ2 |
| F1-6 | 関連用語のリンク表示（例: 「ハンバーガーメニュー」→「ナビゲーション」） | MVP |
| F1-7 | **曖昧検索（AI）**: 「上からシュッと出てくる通知みたいなやつ」→「トースト」がヒットする自然文検索。名前を知らない初心者の根本課題を解決する最大の差別化機能 | フェーズ2（有料機能候補） |

## F-7. 集客・継続機能（2026-07-15 承認済みアイディア）

| ID | 要件 | 優先度 |
|---|---|---|
| F7-1 | **用語カードのSNSシェア画像**: 本文はコピペ不可の代わりに、ロゴ透かし入りのシェア用カード画像を公式に生成・配布（転載防止と口コミ拡散の両立） | フェーズ2 |
| F7-2 | **「今日の1語」**: 毎日1用語をプッシュ通知・メールで配信。継続率と再訪問を高める | フェーズ2 |

### カテゴリ案（初期）
- **UI部品**: ボタン、モーダル、トースト、アコーディオン、カルーセル、ハンバーガーメニュー、パンくずリスト、タブ、ドロップダウン…
- **レイアウト**: ヘッダー、フッター、サイドバー、ヒーローセクション、カード、グリッド…
- **HTML/CSS用語**: セマンティック、フレックスボックス、レスポンシブ、メディアクエリ…
- **JS/開発用語**: DOM、イベント、API、フレームワーク、デプロイ…

## F-2. 用語詳細ページ（画像つき解説）

| ID | 要件 | 優先度 |
|---|---|---|
| F2-1 | 用語名（日本語＋英語表記）、読み方 | MVP |
| F2-2 | **実例画像**（実際のUIのスクリーンショット or 図解）を1枚以上表示 | MVP |
| F2-3 | 一言説明（1文）＋詳しい説明 | MVP |
| F2-4 | 「どんな時に使う？」実務での使いどころ | MVP |
| F2-5 | サンプルコード表示（シンタックスハイライト付き） | MVP |
| F2-6 | 関連用語・間違えやすい用語へのリンク | MVP |
| F2-7 | 画像内の該当部品をハイライトして示す注釈 | フェーズ2 |

> 視覚（画像）→ 名前 → 意味 の順で記憶に残す設計にする。
