## 1. コンテンツ保護（サイト・アプリ内コピペ不可）

### 要件
図鑑の解説文・問題文などの独自コンテンツを、サイト/アプリ内でコピー＆ペーストできないようにする。
**目的は無断転載防止（2026-07-15 決定）**。学習体験を損なわないよう、サンプルコードのみコピーボタンを提供する（転載リスクが低く、学習に必要なため）。

### 実現方法（Web）
| 手段 | 効果 | 備考 |
|---|---|---|
| CSS `user-select: none` | テキスト選択を無効化 | 最も簡単。基本はこれ |
| `copy` イベントのキャンセル | Ctrl+C を無効化 | JSで実装 |
| 右クリックメニュー無効化 | コピー・画像保存の抑止 | UX低下に注意 |
| 画像への透かし（アプリ名ロゴ） | 転載時の出所明示 | 図解画像に薄く入れる |

### 注意点（重要）
- **技術的に完全なコピー防止は不可能**（開発者ツール・スクリーンショットは防げない）。あくまで「抑止」。
- **サンプルコードは例外にするか要検討**: 学習用コードまでコピペ不可にすると学習体験を損なう可能性。
  - 案A: コードも不可（手で打たせて覚えさせる = 写経学習）
  - 案B: コードのみ「コピーボタン」を用意（有料会員限定にする手も）
  - → 親ドキュメントの要確認事項 Q1 と合わせてオーナー判断待ち
- 利用規約に「無断転載禁止」を明記し、法的な保護も併用する。

## 2. 性能

| 項目 | 目標 |
|---|---|
| ページ表示速度 | 主要ページ 2秒以内（LCP） |
| 検索応答 | 500ms以内 |
| 画像 | WebP/AVIF＋遅延読み込みで軽量化 |

## 3. 対応環境
- スマホファースト（学習者はスマホ利用が多い想定）
- 対応ブラウザ: Chrome / Safari / Edge / Firefox 最新版
- レスポンシブ対応（スマホ / タブレット / PC）
- PWA対応（ホーム画面追加・オフライン閲覧はフェーズ2）

## 4. セキュリティ
| 項目 | 内容 |
|---|---|
| 通信 | 全ページHTTPS |
| パスワード | ハッシュ化保存（認証基盤に委譲: Firebase Auth / Supabase Auth 等） |
| 決済情報 | 自前で保持しない（Stripeに委譲） |
| 個人情報 | プライバシーポリシー整備、退会時のデータ削除 |

## 5. SEO・集客
- 図鑑の各用語ページを**無料部分は検索エンジンにインデックスさせる**（用語検索からの流入が最大の集客チャネル）
- ※コピペ不可設定とSEOは両立可能（クローラはHTMLを読むため）
- OGP設定（SNSシェア時に用語カードが見えるように）

## 6. 法令・規約
- 特定商取引法に基づく表記（サブスク販売のため必須）
- 利用規約 / プライバシーポリシー
- 解約導線をわかりやすく（サブスクのトラブル防止）

## 7. 運用
- 用語データはDB管理し、管理画面（または管理用スクリプト）から追加・修正できること
- エラー監視（Sentry等）とアクセス解析（GA4等）を導入
