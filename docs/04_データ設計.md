## 2. 主要テーブル定義

### terms（用語）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | 主キー |
| slug | text | URL用（例: `hamburger-menu`）ユニーク |
| name_ja | text | 用語名（日本語） |
| name_en | text | 英語表記 |
| reading | text | 読み（検索の表記ゆれ対応用） |
| category_id | uuid | カテゴリFK |
| level | int | 難易度 1=初級 2=中級 3=上級 |
| summary | text | 一言説明 |
| description | text | 詳しい説明（Markdown） |
| use_case | text | どんな時に使うか |
| sample_code | text | サンプルコード |
| is_premium | bool | 有料会員限定か |
| related_term_ids | uuid[] | 関連用語 |
| created_at / updated_at | timestamp | |

### term_images（実例画像）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | |
| term_id | uuid | FK |
| url | text | ストレージURL |
| caption | text | 画像の説明 |
| sort_order | int | 表示順 |

### users（ユーザー）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | 認証基盤のUIDと一致 |
| email | text | |
| display_name | text | |
| plan | text | `free` / `premium` |
| stripe_customer_id | text | |
| created_at | timestamp | |

### questions（問題）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | |
| term_id | uuid | 出題対象の用語FK（結果→図鑑への導線に使う） |
| mode | text | `beginner` / `intermediate` / `advanced` |
| type | text | `choice4`（4択）/ `image_choice`（画像当て）/ `input`（記述） |
| question_text | text | 問題文 |
| image_url | text | 問題用画像（任意） |
| choices | jsonb | 選択肢配列 |
| answer | text | 正解 |
| explanation | text | 解説 |
| is_premium | bool | 有料限定か |

### quiz_results（成績）
| カラム | 型 | 説明 |
|---|---|---|
| id | uuid | |
| user_id | uuid | FK |
| mode | text | |
| score / total | int | 正答数 / 出題数 |
| wrong_term_ids | uuid[] | 間違えた用語（復習導線用） |
| taken_at | timestamp | |

### subscriptions（サブスク）
| カラム | 型 | 説明 |
|---|---|---|
| user_id | uuid | FK |
| stripe_subscription_id | text | |
| status | text | `active` / `canceled` / `past_due` |
| current_period_end | timestamp | 有効期限 |

> サブスク状態の正は**Stripe側**。Webhookで同期する。

---

## 3. 検索の表記ゆれ対応
- `name_ja` / `name_en` / `reading` / 別名（エイリアス）カラムを対象に部分一致検索
- 例: 「もーだる」「modal」「モーダルウィンドウ」→ すべて「モーダル」にヒット
- 規模が小さいうちはDBの `ILIKE` で十分。増えたら全文検索を検討
