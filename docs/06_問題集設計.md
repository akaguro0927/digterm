# 06. 問題集設計（子ドキュメント）

> 親: [00_要件定義書.md](./00_要件定義書.md)
> **実装状況（2026-07-15）**: 初心者/中級者/上級者モード＋実力試験をプロトタイプに実装済み（`/quiz`）。問題は用語データから自動生成。成績保存はM3（アカウント）待ち。

## 0. 実力試験モード（追加仕様・実装済み）
- 全カテゴリから20問、制限時間10分、合格ライン正答率80%
- 通常モードと違い**答え合わせは最後にまとめて**表示（試験らしい緊張感）
- 4択中心＋記述問題をミックス。残り1分でタイマーが警告表示
- 将来: 合格証の画像発行（SNSシェア用・透かし入り）を検討

---

## 1. コンセプト
図鑑で「見て覚える」→ 問題集で「思い出して定着させる」。
間違えた問題から図鑑の該当ページへ戻れる**復習ループ**を作る。

## 2. モード設計

### 初心者モード（MVP・一部無料）
| 項目 | 内容 |
|---|---|
| 対象 | 用語をこれから覚える人 |
| 形式 | 4択クイズ |
| 出題例 | ①画像を見せて「この部品の名前は？」 ②用語を見せて「正しい説明は？」 |
| 範囲 | 難易度1（初級）の用語のみ |
| 特徴 | **画像→名前** の紐付けを最優先。解説つき |

### 中級者モード（フェーズ2・有料）
| 項目 | 内容 |
|---|---|
| 形式 | 4択＋穴埋め（コードの一部を選ぶ） |
| 出題例 | 「レスポンシブ対応に使うCSS機能はどれ？」「この動きをするUIは？」 |
| 範囲 | 難易度1〜2、用途・使い分けを問う |

### 上級者モード（フェーズ2・有料）
| 項目 | 内容 |
|---|---|
| 形式 | 記述（用語名をタイプして回答）＋ケース問題 |
| 出題例 | 画像を見て部品名を**入力**する（選択肢なし）/「この要件ならどの部品を使う？」 |
| 範囲 | 全難易度。実務での判断力を問う |

> 上級者モードで「タイプさせる」のは、コピペ不可方針と同じ思想（手を動かして覚える）。

## 3. 出題の仕組み

| 項目 | 仕様 |
|---|---|
| 1セット | 10問（サクッと終わる長さ） |
| 出題順 | ランダム。選択肢の並びもランダム |
| 誤答選択肢 | 同カテゴリの用語から自動生成（間違えやすいものが混ざる） |
| 結果画面 | スコア＋間違えた問題の解説＋**該当用語の図鑑リンク** |
| 成績保存 | ログインユーザーのみ（→登録の動機付けにする） |

## 4. 学習を続けさせる仕掛け（フェーズ2）
- 苦手用語の自動復習出題（間違えた用語が再出題されやすくなる）
- 連続学習日数（ストリーク）表示
- 習得率バッジ（カテゴリごとに「HTML用語 80%習得」など）

## 5. 問題データの作り方
- `questions` テーブルに登録（[04_データ設計.md](./04_データ設計.md) 参照）
- 初期問題はAIで下書き生成 → 人がレビューして登録（要確認事項Q5）
- 4択の基本問題は用語データ（名前・説明・画像）から**自動生成**できる設計にすると、用語を追加するだけで問題も増える
