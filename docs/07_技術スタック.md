## 1. 推奨構成（案A）

| レイヤー | 技術 | 選定理由 |
|---|---|---|
| フロント | **Next.js（React）+ TypeScript** | 用語ページのSEOに必須なSSR/SSGが得意。PWA化も容易 |
| スタイル | Tailwind CSS | 素早くきれいなUIを作れる |
| 認証・DB | **Supabase**（PostgreSQL + Auth + Storage） | 認証・DB・画像ストレージが1つで揃う。無料枠が広い |
| 決済 | **Stripe**（Checkout + Customer Portal + Webhook） | サブスクの定番。カード情報を自前で持たない |
| デプロイ | **Cloud Run**（コンテナ）または Vercel | ※Cloud Runは既に `deploy_cloudrun.ps1` で経験あり。流用可能 |
| 画像最適化 | next/image + WebP | 図鑑は画像が多いため必須 |
| 監視/解析 | Sentry + GA4 | エラー検知と利用分析 |

## 2. 代替案（案B: Firebase寄せ）
| レイヤー | 技術 |
|---|---|
| 認証・DB | Firebase Auth + Firestore + Cloud Storage |
| デプロイ | Firebase Hosting + Cloud Run |

- Googleエコシステムで統一できる。ただしFirestoreは検索（部分一致）が弱く、図鑑検索には**PostgreSQL（Supabase）の方が向く** → 案Aを推奨。

## 3. コンテンツ保護の実装ポイント
- 全文コンテンツに `user-select: none` ＋ `copy` イベント抑止（[02_非機能要件.md](./02_非機能要件.md)）
- 有料コンテンツの出し分けは**サーバーコンポーネント/API側**で行う（クライアントに送らない）
