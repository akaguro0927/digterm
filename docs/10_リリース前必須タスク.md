## 🔴 A. セキュリティ（今すぐ）
- [ ] 🔴👤 **Supabase の service_role キーを再生成**
  - 理由：過去にチャットへ露出したため。Stripe Webhook で使うので、使う前に必ず新しいものへ。
  - 手順：Supabase Dashboard → Project Settings → API → `service_role` を Reveal/Rotate → 新キーを `.env.local` の `SUPABASE_SERVICE_ROLE_KEY` に設定（**絶対にクライアントへ出さない／gitに入れない**）。

## 🟠 B. データベース（本番を動かす前提）
- [ ] 🟠👤 **`supabase/schema.sql` を Supabase SQL Editor で実行**
  - 現状 `.env.local` は URL+anon のみ。`profiles / subscriptions / purchases / favorites / quiz_results / journey_progress / seen_terms` などの表がまだ本番に無い可能性。
  - 手順：Supabase Dashboard → SQL Editor に `schema.sql` を貼り付けて実行（再実行OKな冪等スクリプト）。
  - 完了後：ログインして お気に入り/進捗/既読 が同期されるか確認（未作成でもアプリは壊れないが、同期は効かない）。
