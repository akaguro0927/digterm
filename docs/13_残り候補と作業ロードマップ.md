## 🔜 残りの候補（未着手・優先度順）

### B. 孤立している図鑑用語をレッスンに接続（無料・図鑑の価値UP）★次おすすめ
- `src/data/terms.ts` には多数の用語があるが、`journey.ts` の各レッスンの
  `relatedSlugs` に載っていない＝どのレッスンからもリンクされない「孤立用語」が残る。
- やり方: 各レッスンの内容に合う用語slugを `relatedSlugs` に追記していく。
- 孤立チェックの目安: `terms.ts` の slug 一覧 と、`journey.ts` 内の全 `relatedSlugs` の
  差分を見る。前セッションで backend 章(a12)＋6レッスン分は接続済み。
- 参考: `VISUAL_SLUGS`（`src/data/visualTerms.ts`）にある＝図鑑に表示される用語なので、
  そこにある孤立slugを優先的にレッスンへ紐づけると効果が高い。

### C. コマンド図鑑の充実（Aの次に軽い）
- `git add/commit/push/pull/clone/branch/checkout`、`ssh`、`code -r`、`start`,
  `explorer .`、`tree`、`findstr`、`set`（環境変数）などを `winCommands` に追加。
- Mac/Linux対応の需要が出たら `shell` に "bash" を足す設計に拡張可能。
